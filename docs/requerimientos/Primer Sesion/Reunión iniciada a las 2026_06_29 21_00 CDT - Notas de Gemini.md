### **Resumen**

Definición de requerimientos web para retiros y estructuración del movimiento con integración de canales de comunicación directa.

**Requerimientos y navegación web**  
El sitio integrará formularios de inscripción, mapas, preguntas frecuentes y un menú de clasificación por perfiles de usuario. Se busca facilitar la navegación automática hacia los contactos adecuados.

**Multimedia y estrategia comunicación**  
La estrategia combina videos en redes para jóvenes con un sitio web que genera confianza parental. Se integrará WhatsApp para asegurar una comunicación humana y personalizada.

**Estructura organizativa institucional**  
Se decidió adoptar una estructura de coordinadores por procesos basada en la asociación JMB para formalizar el movimiento. El sitio web reflejará esta identidad orgánica y juvenil.
